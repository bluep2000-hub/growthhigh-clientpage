# 보울게임즈 녹음 자동화 실전 검증

2026-09-21 보울게임즈 녹음 2건으로 접수 이후 흐름을 검증했다.

## 완료

- 고객사 연결: `수집대기/보울게임즈` → `bowlgames`
- 원본 파일명은 바꾸지 않고 앞의 `YYMMDD_`를 실제 통화일로 사용
- 녹음 2건 전사 성공
- 회의록 2건 생성 성공
- Notion 커뮤니케이션보드에 고객 비공개 초안 2건 생성
- 두 건 모두 `WAITING_PUBLIC_APPROVAL`이며 고객 공개·페이지 반영은 0건

회의록 기본 모델은 Gemini API가 권장하고 실제 성공한 `gemini-3.6-flash`로
조정했다. 일시적인 API 실패는 다음 실행에서 회의록 생성부터 이어서 재시도한다.
형식 검사에서 멈춘 항목은 자동 재시도하지 않고 PM 확인 대상으로 유지한다.

## 확인된 운영 조건

Google Drive 웹 업로드는 완료됐지만 이 PC의 Drive Desktop 로그에는
`Syncing is paused`가 기록돼 로컬 접수함에 파일이 나타나지 않았다. 이번 검증은
사용자가 선택해 업로드한 동일한 로컬 원본 사본을 임시 접수함에서 처리했다.
파일 해시를 처리 장부에 기록했으므로 Drive 동기화가 재개돼도 같은 파일을 다시
처리하지 않는다.

자동 예약은 활성화하지 않았다. 다음 운영 전에는 사용자가 Drive Desktop 동기화
재개 여부를 결정해야 한다.

## 다음 행동

1. PM이 Notion 비공개 초안 2건의 기업명·내용을 확인한다.
2. 고객에게 공개할 건만 `고객 공개`를 체크한다.
3. 수동 1회 실행으로 승인 감지와 보울게임즈 고객 페이지 반영을 확인한다.
