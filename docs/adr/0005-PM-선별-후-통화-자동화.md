# PM이 선별한 통화녹음의 접수 이후만 자동화한다

개인·업무 혼용 삼성폰에서 연락처 그룹과 Tasker·FolderSync로 고객 통화를 자동 선별하는 안을 검토했으나, One UI 차이와 권한 설정이 PM의 일상 운영을 복잡하게 하고 잘못된 선별은 개인 통화를 외부로 보낼 수 있다. MVP에서는 PM이 기록할 녹음본과 고객사를 직접 확인해 고객사별 Google Drive 접수함에 올리고, 파일이 접수된 이후의 전사·요약·Notion 기록·클라이언트 페이지 반영만 자동화한다.

## Consequences

- 휴대전화 연락처 그룹, Tasker, FolderSync와 전용 Android 수집기는 MVP에서 보류한다.
- PM은 녹음 한 건마다 고객사 접수함을 고르는 한 번의 수동 작업을 한다. 파일 이름 변경이나 터미널 실행은 요구하지 않는다.
- 전체 통화녹음 폴더를 동기화하지 않으며, 접수하지 않은 통화의 음성·메타데이터는 휴대전화 밖으로 보내지 않는다.
- 자동화 KPI는 전체 고객 통화가 아니라 접수된 녹음의 처리율·처리 시간·중복·실패 가시성을 측정한다.
- 고객사는 접수함 경로로 확정하고 파일 내용이나 연락처명으로 추측하지 않는다.
