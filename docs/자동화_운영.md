# 통화·미팅 기록 자동 적재 — 운영 문서

녹음 → 전사 → 요약 → 노션 → 클라이언트 페이지까지 하루 한 번 자동으로 돈다.
스케줄러가 파이썬이 아니라 **클로드 예약 세션**인 이유는, 요약(talk-summary)이
스킬이고 미분류 파일을 본문 보고 판단하는 단계가 있기 때문이다.

## 아직 켜지 않았다

**제미나이 API 결제를 연결하기 전에는 켜지 않는다.**
무료 등급은 보낸 내용을 구글이 학습에 쓰고 사람이 검토할 수 있다.
고객사 통화가 거기로 새면 안 된다. 결제 연결은 v1 완성 후에 하기로 했다.

켜는 순서:
1. https://aistudio.google.com/app/apikey 에서 키에 결제 계정 연결
2. 아래 지시문으로 예약 세션 등록 (하루 1회)
3. 첫 회차는 사람이 결과를 확인한다

## 예약 세션 지시문 (그대로 붙여넣는다)

```
그로스하이 클라이언트페이지 — 통화·미팅 기록 적재.
작업 폴더: <이 PC 의 리포 경로를 여기에 넣는다>

1. 새 녹음 전사
   python src/transcribe_drive.py
   "전사할 새 녹음본이 없다" 가 나오면 여기서 끝낸다. 한 줄 보고하고 종료.

2. 미분류 정리
   드라이브 폴더에 *_미분류_*.txt 가 있으면 본문을 읽고 어느 고객사인지 정한다.
   노션 「공유페이지」 DB에 있는 기업 중에서만 고른다. 목록에 없는 이름은 쓰지 않는다.
   확실하면 260903_위프코리아_통화.txt 형태로 파일 이름을 고친다.
   애매하면 그대로 두고 보고에 적는다. 지어내지 않는다.

3. 요약을 노션에 기록
   talk-summary 스킬을 호출한다.

4. 클라이언트 페이지 갱신
   이번에 새로 기록된 고객사에 대해서만 실행한다.
   python src/build_client.py --client <슬러그>
   그다음 git add -A && git commit && git push

5. 보고 (3줄 이내)
   전사 N건 / 노션 기록 N건 / 배포 N곳 / 미분류로 남은 파일 이름
```

붙여넣기 전에 `작업 폴더` 한 줄을 이 PC 의 경로로 바꾼다.

| 고객사 | 슬러그 |
|---|---|
| 위프코리아 | `whiffkorea` |

v1 은 **위프코리아 한 곳만** 검증 대상이다. 나머지는 v1 이 끝난 뒤에 넓힌다.

## 사람이 하는 일

컨설턴트가 녹음하고, 녹음 파일을 구글드라이브 「클라이언트 통화 미팅기록」
폴더에 올린다. 그게 전부다. 파일 이름은 손대지 않아도 된다.

이름을 손댈 수 있다면 `[위프코리아]` 처럼 대괄호로 고객사를 넣어 두면
전사기가 바로 알아본다. 안 넣어도 요약 단계에서 본문 보고 정한다.

## 문제가 생기면

| 증상 | 원인과 조치 |
|---|---|
| `폴더를 못 찾았다` | 구글 드라이브 데스크톱이 꺼져 있다. 켠다 |
| `GEMINI_API_KEY 가 없다` | `.env` 확인 |
| 같은 녹음이 다시 전사된다 | `.transcribed.json` 이 지워졌다. 이 파일이 처리 기록이다 |
| `미분류` 가 계속 쌓인다 | 파일 이름에 `[고객사]` 를 넣도록 컨설턴트에게 안내 |
