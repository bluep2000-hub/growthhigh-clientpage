# PM·대표 전체 고객페이지 관리 권한

2026-09-21 사용자 결정으로 내부 권한 범위를 변경했다.

- Notion `클라이언트페이지 내부 권한` 표에 정확히 한 번 등록된 Google 이메일이어야 한다.
- 역할은 `PM` 또는 `대표`만 허용한다.
- 두 역할은 모두 시스템에 등록된 전체 고객페이지를 조회·편집할 수 있다.
- `담당 기업` 관계는 운영 메모로 남겨도 되지만 권한 판단에 쓰지 않는다.
- 이메일 중복·미등록·알 수 없는 역할·Notion 조회 실패는 계속 거절한다.
- 요청 URL의 기업과 본문의 기업이 다른 교차 기업 요청은 계속 거절한다.

권한표는 사용자가 지정한 Notion `공유페이지` 아래로 이동했다.
이동하면서 끊긴 기존 `DB 업로드 파이프라인` 연결을 다시 추가했다.
Notion API의 데이터베이스 조회와 행 조회는 모두 200으로 복구됐다.

## 검증과 배포

- 전체 자동 검사: 30개 파일, 337개 통과
- Worker 배포: `growthhigh-clientpage-private`
- 배포 버전: `86c8a57f-390f-4c21-ba75-d820608a208c`
- 위프코리아·보울게임즈 상태 확인: HTTP 200, 고객 접속 준비 완료
- 권한표 5행 중 이메일과 유효 역할이 모두 있는 로그인 가능 행은 2개다.
  나머지 PM 3명은 이메일을 입력한 뒤 로그인할 수 있다.
