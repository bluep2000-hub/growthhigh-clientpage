# 담은결 제작 진행

2026-09-23. 사용자가 지정한 기존 공유페이지에서 보울게임즈와 같은 제작 절차를 시작했다.
Notion 원본 구성과 타임테이블 배포를 완료했다. 전체 고객 전달 검수는 진행 중이다.

## 완료

- 기존 담은결 공유페이지에 기업 DB·담당자 연결이 있음을 확인했다.
- 중복 조회 후 영문 주소 `dameungyeol`을 등록했다.
- 기업 정보 원본, 주요 자료 4건, 기업별 프로젝트 연결 보기, 고객 공개 소통 연결 보기를 구성했다.
- 프로젝트 보기는 기업 관계, 소통 보기는 기업명과 고객 공개 체크로 필터링했다.
- 양승현 PM의 이메일 입력·역할 PM·이메일 일치 행 1건을 실제 API로 확인했다.
  권한 코드는 매 요청에서 Notion을 읽으므로 별도 배포가 필요 없다. 본인 Google 로그인은 미확인이다.

## 다음 입력과 남은 작업

1. 제공 이미지 기준 타임테이블은 아래 검증 기록대로 반영 완료했다.
   기존 9월 23일 미팅 원본의 연도 불일치는 수정하지 않았다.
2. 연결한 1·2·3차 자료와 기획 미팅 페이지는 API상 사이트 미게시다. Notion 원본 링크만 정리했으며
   고객 데이터룸 노출을 완료했다고 보고하지 않는다. 고객 열람 방식·게시 주소 확인이 필요하다.
3. 사용자 고객 비밀번호 설정과 최초 비공개 DB 빌드 완료. 로그인된 PM 화면에서 확인했으며,
   별도 고객 비밀번호 세션의 전체 화면 검수는 남아 있다.
4. 데이터룸·추천사업의 기업 한정 UI/API, 로드맵 연결은 보울게임즈 구현을 재사용해 보강한다.
5. 녹음 접수함·고객사 매핑·메일 수집 연결·로고는 미확인이다. 새 예약은 만들지 않았다.

기존 기업 데이터, 자료 공개 권한, 예약 작업은 변경하지 않았다.
실제 고객 자료와 PM 이메일 원문은 이 문서에 복사하지 않는다.
