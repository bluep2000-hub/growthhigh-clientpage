# 신규 클라이언트페이지 제작 워크플로우

## 목적

신규 고객사를 추가할 때 위프코리아 코드를 복사하지 않는다. 고객사 이름과 영문 주소만 정하면
같은 보안 서버와 화면을 재사용하고, 실제 내용은 그 고객사의 Notion 데이터에서 읽는다.

## PM이 준비할 것

1. `📚공유페이지 DB`에 연결할 기업이 등록되어 있어야 한다.
2. 고객에게 보여 줄 영문 주소를 정한다. 예: 보울게임즈는 `bowlgames`.
3. 고객에게 전달할 비밀번호를 정한다. 비밀번호는 Notion이나 GitHub에 기록하지 않는다.

PM과 대표는 `클라이언트페이지 내부 권한` 표에 Google 이메일과 역할을 한 번만 등록한다.
등록된 PM·대표는 모든 고객페이지를 관리하며 `담당 기업` 관계는 권한 판단에 쓰지 않는다.

## 제작 절차

1. **Notion 기본 페이지 생성**
   - 페이지명: `<기업명> 클라이언트페이지(테스트)`
   - 기업 DB, 담당자, 업종, 페이지 유형, 영문 주소를 연결한다.
   - 공유페이지 행의 페이지 아이콘에 고객사 로고를 등록한다. 빌더가 이 아이콘을 내려받아 고객 화면에 사용한다.
2. **기존 데이터 연결**
   - 기업정보와 기존 진단·미팅 자료 링크를 페이지에 모은다.
   - 프로젝트 DB는 `고객사 정보`가 해당 기업인 행만 자동으로 보이게 연결한다.
   - 커뮤니케이션보드는 해당 기업이면서 `고객 공개`가 승인된 행만 자동으로 보이게 연결한다.
   - 새 고객사 추가 때 기존 자료를 복사하지 않고 원본 DB를 연결한다.
3. **소통 분류 추가**
   - 커뮤니케이션보드의 `기업명` 선택 목록에 고객사를 추가한다.
   - 다우오피스에 `Inbox.고객사.<기업명>` 전용 메일함이 있으면 그 메일을 수집한다.
   - 전용 메일함이 아직 없으면 `Inbox.그로스하이`에서 제목에 `[기업명]`이 정확히
     붙은 메일만 수집한다. 이름 일부가 비슷한 다른 고객사 메일은 가져오지 않는다.
   - 수집한 메일은 커뮤니케이션보드에 `고객 공개`가 체크된 상태로 넣는다.
     숨겨야 할 메일만 담당 PM이 `고객 공개` 체크를 해제한다.
4. **생성 전 확인**
   - 기업정보, 프로젝트, 일정이 해당 고객사 데이터로 읽히는지 시험한다.
   - 없는 추천사업·조달성과·소통은 오류가 아니라 빈 화면으로 둔다.
5. **보안 주소 활성화**
   - 담당자가 `https://client.growthhigh.co.kr/<영문주소>/?edit`에 Google 계정으로 로그인한다.
   - 고객 비밀번호를 두 번 입력해 저장한다. 이때부터 매일 09:00·13:00·18:00 정기 갱신 대상이 된다.
6. **실제 페이지에서 공지 작성**
   - Notion 공지 DB를 새로 만들거나 연결하지 않는다.
   - `https://client.growthhigh.co.kr/<영문주소>/page/?edit#notice`에서
     `담당자 편집`을 켜고 공지를 직접 작성·미리보기·게시한다.
   - 게시본과 이전 판은 보안 서버의 D1에 저장된다.
7. **최종 확인과 전달**
   - 즉시 한 번 갱신한 뒤 고객용 주소와 읽기 전용 화면을 확인한다.
   - `📚공유페이지 DB`의 `페이지 주소`를 최종 주소로 기록한다.
   - 고객에게 주소와 비밀번호를 서로 다른 연락 수단으로 전달한다.

## 자동 처리되는 부분

- 비밀번호가 등록된 모든 고객사를 매일 세 번 갱신한다.
- 고객사별 데이터와 로그인 범위를 분리한다.
- 한 고객사 갱신이 실패해도 다른 고객사는 계속 갱신하며, 실패한 고객사는 이전 정상 화면을 유지한다.

## 새 고객사마다 사람이 하는 일

- 고객 공개가 가능한 원본 내용을 Notion에 입력하고 승인한다.
- 최초 고객 비밀번호를 정해 저장한다.
- 실제 클라이언트페이지에서 공지를 직접 작성하고 게시한다.
- 실제 고객 화면을 한 번 확인한 뒤 주소와 비밀번호를 전달한다.

## 보울게임즈 현재 상태

- 영문 주소: `bowlgames`
- 클라이언트페이지 행, 기업 연결, 담당자, 업종 연결 완료
- 잘못 만들었던 Notion 공지 DB 연결 해제 완료. 기존 DB는 삭제하지 않고 보존
- 커뮤니케이션보드의 `보울게임즈` 분류 추가 완료
- 기존 진단·미팅 자료 링크와 기업정보 연결 완료
- 프로젝트 및 고객 공개 소통 자동 연결 보기 생성 완료
- 다우오피스의 보울게임즈 메일 5건을 원본 DB에 수집 완료
- 커뮤니케이션보드에는 같은 5건을 기본 공개 상태로 연결한다.
- 고객 비밀번호 설정, 보안 주소 활성화, 실제 화면 검수 완료
- 보울게임즈 로고를 공유페이지 원본 아이콘에 등록하고 운영 화면 반영 확인 완료
- 녹음 자동화 고객사 연결: `수집대기/보울게임즈` → `bowlgames`
- 실제 페이지에서 첫 공지 게시 및 D1 게시본 저장 확인 완료
- 즉시 갱신과 고객 읽기 화면 검수 완료. 고객 전달 전 최종 내용 확인만 남음
