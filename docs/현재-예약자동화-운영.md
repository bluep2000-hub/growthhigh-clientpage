다른 PC에서 코드를 작업했다면 **이 폴더에서도 `git pull --rebase`** 해야 예약 작업에
반영된다. 이 PC가 켜져 있고 사용자가 로그인한 상태에서 Google Drive Desktop의
접수함을 읽을 수 있어야 한다. 새 PC에서 두 번째 예약 작업을 동시에 켜지 않는다.

## PM이 하는 일

1. 업무 통화인지와 고객사를 확인한 뒤 **선택한 녹음 파일만** Google Drive의
   `클라이언트 통화 미팅기록/수집대기/{고객사}`에 넣는다. 개인 통화 폴더 전체를
   자동 업로드하지 않는다. 파일 이름을 고치지 않아도 된다.
2. 같은 이름의 `수집대기` 폴더가 하나 더 있다. 현재 이 PC의 예약 작업은
   `수집대기`(Drive Desktop에서 `(1)`이 붙지 않은 쪽)를 읽는다. 폴더 이름만
   검색해 업로드하지 말고, 운영 접수함의 직접 링크를 사용한다. 중복 폴더는
   확인 없이 삭제하거나 이동하지 않는다.
3. 생성된 Notion 소통 기록은 기본적으로 고객 공개다. PM이 내용을 확인·수정하고,
   숨길 건만 `고객 공개`를 해제한다. 중요 소통 여부도 PM이 결정한다.
4. 공지는 Notion이 아니라 실제 클라이언트페이지의 편집 화면에서 작성·게시한다.
