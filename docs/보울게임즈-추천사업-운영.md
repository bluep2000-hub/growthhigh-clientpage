# 보울게임즈 추천 지원사업 관리

보울게임즈 담당자는 고객페이지 `?edit#open`에서 Google 로그인 후 「담당자 편집」을 켠다.
신청 가능한 게임 관련 사업이 먼저 보이며, 다른 사업과 마감된 사업은 검색할 수 있다.
요약·대상·지원 규모·마감일을 읽고 「검토서 자세히 보기」로 원문을 확인한 뒤
「추천 추가」를 누른다. 추천 중인 사업은 「추천 취소」로 제외하고,
「즐겨찾기」로 지정·해제한다. 담당자가 고르는 일은 자동화하지 않는다.
저장 성공 후 고객페이지와 별도 검토서를 새로 열면 최신 목록이 보인다. GitHub 조작이나
기업 데이터 전체 재빌드는 필요하지 않다. 추천 취소는 공고 원본 삭제가 아니라 이 기업의
추천 목록에서 제외하는 작업이다. 즐겨찾기 사업은 고객페이지와 검토서의 진행 중인
사업 맨 위에 표시된다.

## 데이터 경계

- 보울게임즈 선택 목록의 원본은 비공개 Cloudflare D1 `recommendation_items`다.
- 사업명·요약·대상·지원 규모·마감일·검토서 주소는 기존 `growthhigh-policy/data-full.json`에서
  읽는다. 2026-09-21 확인 시 434건이었다.
- 고객페이지의 인증된 `/bowlgames/api/customer`는 최신 선택 목록과 정책정보를
  합쳐 읽는다. 별도 검토서는 `/bowlgames/recommendations/share`의 선택 식별자만
  읽고 자기 정책정보 목록에서 표시한다. 두 화면 모두 새로고침 시 갱신된다.
- 별도 검토서는 기존처럼 공유 주소로 열리는 공개 화면이다. 이 공개 범위 때문에
  선택 식별자만 읽는 API도 공개다. 기업 데이터 본문·인증정보는 제공하지 않는다.
- 기존 Firestore 재생목록은 다른 기업·브리핑용으로 남긴다. 보울게임즈는 이 원본을
  사용하지 않으며, 정책정보 사이트의 직접 편집 화면에서도 같은 이름의 새 문서를
  만들지 못하게 했다.

## 실패와 확인

- 담당자 인증이 없거나 다른 기업으로 보내는 편집 요청은 거절한다.
- 추가할 공고는 현재 정책정보에 존재해야 하며, 마감된 공고는 추가할 수 없다.
  같은 공고를 다시 추가해도 중복 항목이 생기지 않는다.
- 정책정보의 날짜와 마감 시각을 함께 판정한다. 2026-09-21 기준 제목에 ‘게임’이
  들어간 12건 중 신청 가능한 것은 2건이며, 나머지 10건은 마감됐다.
- 즐겨찾기는 이미 추천한 사업에만 적용되며, 추천을 취소하면 즐겨찾기도 함께 사라진다.
- 정책정보 조회가 실패하면 새 추천을 빈 정상 목록으로 가장하지 않고 고객 화면에
  재확인 안내를 보인다. 저장 실패 시 담당자에게 실패를 알리고 목록을 바꾸지 않는다.
- `https://curation.growthhigh.co.kr/playlist.html?list=보울게임즈&share=1`
  에서 별도 검토서 표시를 확인한다. 데이터가 0건이면 빈 상태가 정상이다.
- 2026-09-21 배포한 비공개 Worker 버전은
  `7288ad65-6c28-4b87-970c-8ac8ae3a0352`다. 운영 도메인에서 선택 목록
  읽기 200, 미인증 편집 401, 샘플 경로 404를 확인했다. 실제 검토서
  `curation.growthhigh.co.kr`에서 빈 목록이 정상 표시되는 것도 확인했다.
- 운영 Chrome의 보울게임즈 담당자 화면에서 「추천 사업 관리」 진입과 사업명
  검색·추가 버튼 표시를 확인했다. 실제 추천 사업은 담당자가 선택해야 하므로
  운영 데이터에 임의로 추가하지 않았다.
- 2026-09-21 읽기 확인 시 `15-game-investment` 1건이 이미 선택돼 있다.
  4월 마감 사업이므로 고객 화면에서는 숨기고, 담당자 화면에서는 마감 상태와
  「추천 취소」를 보여 준다. 임의로 삭제하지 않는다.
- 같은 날 운영 담당자 화면에서 저장된 1건의 요약·마감·취소 버튼과 신청 가능한
  게임 관련 2건의 요약·지원 내용·검토서 링크·추가 버튼을 확인했다. 별도 검토서
  즐겨찾기 정렬 배포도 확인했다. 새 사업의 실제 추가·즐겨찾기 지정은 담당자
  선택 전이므로 운영 데이터에 수행하지 않았다.

## 확대 전 확인

이 연결은 보울게임즈 파일럿에만 적용한다. 다른 기업은 기존 Firestore 재생목록을
계속 사용한다. 기존 정책정보 사이트의 브라우저 직접 쓰기 권한은 별도 보안 점검
대상이다. 공개 화면에서 편집 버튼을 숨기는 것은 서버 쓰기 권한을 대신하지 않는다.
