# 보울게임즈 추천 지원사업 관리

보울게임즈 담당자는 고객페이지 `?edit#open`에서 Google 로그인 후 「담당자 편집」을 켜고
사업명을 검색해 추가하거나 「빼기」를 누른다. 담당자가 고르는 일은 자동화하지 않는다.
저장 성공 후 고객페이지와 별도 검토서를 새로 열면 최신 목록이 보인다. GitHub 조작이나
기업 데이터 전체 재빌드는 필요하지 않다. 빼기는 공고 원본 삭제가 아니라 이 기업의
추천 목록에서 제외하는 작업이다.

## 데이터 경계

- 보울게임즈 선택 목록의 원본은 비공개 Cloudflare D1 `recommendation_items`다.
- 사업명·마감일·지원 규모·검토서 주소는 기존 `growthhigh-policy/data-full.json`에서
  읽는다. 2026-09-21 확인 시 434건이었다.
- 고객페이지의 인증된 `/bowlgames/api/customer`는 최신 선택 목록과 정책정보를
  합쳐 읽는다. 별도 검토서는 `/bowlgames/recommendations/share`의 선택 식별자만
  읽고 자기 정책정보 목록에서 표시한다. 두 화면 모두 새로고침 시 갱신된다.
- 별도 검토서는 기존처럼 공유 주소로 열리는 공개 화면이다. 이 공개 범위 때문에
  선택 식별자만 읽는 API도 공개다. 기업 데이터 본문·인증정보는 제공하지 않는다.
- 기존 Firestore 재생목록은 다른 기업·브리핑용으로 남긴다. 보울게임즈는 이 원본을
  사용하지 않으며, 정책정보 사이트의 직접 편집 화면에서도 같은 이름의 새 문서를
  만들지 못하게 했다.

## 실패와 확인

- 담당자 인증이 없거나 다른 기업으로 보내는 편집 요청은 거절한다.
- 추가할 공고는 현재 정책정보에 존재해야 하며, 마감된 공고는 추가할 수 없다.
  같은 공고를 다시 추가해도 중복 항목이 생기지 않는다.
- 정책정보 조회가 실패하면 새 추천을 빈 정상 목록으로 가장하지 않고 고객 화면에
  재확인 안내를 보인다. 저장 실패 시 담당자에게 실패를 알리고 목록을 바꾸지 않는다.
- `https://bluep2000-hub.github.io/growthhigh-policy/playlist.html?list=보울게임즈&share=1`
  에서 별도 검토서 표시를 확인한다. 데이터가 0건이면 빈 상태가 정상이다.
- 2026-09-21 배포한 비공개 Worker 버전은
  `17429684-d37a-477c-80d9-04cd627d9c92`다. 운영 도메인에서 선택 목록
  읽기 200·0건, 미인증 편집 401, 샘플 경로 404를 확인했다.

## 확대 전 확인

이 연결은 보울게임즈 파일럿에만 적용한다. 다른 기업은 기존 Firestore 재생목록을
계속 사용한다. 기존 정책정보 사이트의 브라우저 직접 쓰기 권한은 별도 보안 점검
대상이다. 공개 화면에서 편집 버튼을 숨기는 것은 서버 쓰기 권한을 대신하지 않는다.
